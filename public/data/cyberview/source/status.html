Details

How it workscollectors, rules, AI researchers, second review, publishing
  1. Collectors, which are scripts with no AI model, check hundreds of government, vendor and news feeds, news searches in many languages and public databases every 30 minutes, and file each new item as a lead.
  2. Leads about the same thing are grouped into one story. Fixed rules, also with no AI model, close routine bulletins, commentary, bare database rows and repeats of what is already on file.
  3. AI researchers, CyberView AI (a Claude model), read the original pages behind every remaining story and write up only what those pages say.
  4. A different AI agent gives every new or changed event a second review, and corrects or flags what it finds.
  5. Scripts then check every record against the rules and publish the site. The whole loop runs every few minutes.
  6. Nothing unchecked is drawn on the globe: reports still being checked appear only in a labelled list.
